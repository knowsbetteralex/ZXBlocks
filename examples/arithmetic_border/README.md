# Арифметика и скорость

В каждом кадре `speed = 1 + клавиша SPACE`. Условие `counter + speed >= limit`
сравнивает два выражения. При достижении предела счётчик сбрасывается, а цвет
увеличивается на один. Блок бордюра получает выражение `7 − color`.

Без пробела цвет меняется каждые 25 кадров; при удержании SPACE — каждые 13.
Изменяйте `limit` и выражения в редакторе. Это арифметика в обычном событии
кадра; отдельные блоки таймеров/задержек ещё не добавлены.

В редакторе: **Меню → Создать из примера → Арифметика и скорость**.
Из терминала в корне репозитория:

```powershell
python -m zxblocks run examples/arithmetic_border/project.json
```

Значения u8 оборачиваются по модулю 256, а бордюр использует младшие три бита.
Спецификация выражений: [zxblocks/v3](../../docs/BLOCK_IR_V3.md).
